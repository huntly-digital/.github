Plandillo is a task planner that gives you and your coding agents a shared board. Outline a feature in your browser, ask Claude Code to add an implementation checklist, then have Codex record which tests passed. The checklist and test results stay with the task, ready for whoever picks it up next.

Run Plandillo locally or on your own server. Agents connect through the Model Context Protocol (MCP). We maintain the project under the MIT license.

[Explore the repository](https://github.com/huntly-digital/plandillo) · [Run it locally](https://github.com/huntly-digital/plandillo#quick-start) · [Contribute](https://github.com/huntly-digital/plandillo/blob/main/CONTRIBUTING.md)
